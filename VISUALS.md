# GeoTrace 0.1.4 — source previews and street map

The gallery displays provider-published thumbnails for visible rows, with selected-record author/license credit and original-source links. Missing previews stay explicit. **Mostra anteprime** switches between visual and compact metadata views; **Riprova anteprime** retries failed loads. No thumbnails are generated by AI or treated as verified historical evidence. Existing recording timestamps, confidence classes, source references and original metadata are preserved.

The **Street map (OSM)** tab uses native Qt rendering, public OpenStreetMap tiles, Web Mercator projection and a geodesic search circle. Only source coordinates and catalog footprints are plotted. Zoom, pan, recenter, retry and feature selection work independently of the offline coordinate map. Current cartography is explicitly distinguished from historical imagery, with permanent OpenStreetMap attribution. Search areas beyond Mercator's latitude coverage are directed to the offline view.

## Retrieval and cache

`images.py` coordinates asynchronous Qt Network requests. At most two preview and two map requests run concurrently; queued work is bounded and invisible pending work is removed. Requests identify GeoTrace and use normal TLS validation. HTTP redirects are limited to three and must remain on supported HTTPS image hosts. Public previews from Wikimedia, CDSE/CREODIAS, AWS, NASA, USGS and Element84 are supported; S3 URIs and unrelated hosts are not silently rewritten or fetched.

Only the viewed map area is requested, without prefetch or bulk downloads. Cache-Control, Age and Expires are interpreted; tiles without usable expiry metadata use seven days. Disk cache has a 128 MiB body limit and integrity hashes; decoded image memory is bounded. Responses over 3 MiB, unsupported formats/dimensions, non-256-pixel tiles and failed HTTP replies remain unavailable. A cache write failure does not prevent displaying a successfully fetched image. Image cache lives under `%LOCALAPPDATA%/GeoTrace/image-cache`, separate from archived evidence.

NASA normalization extracts official published CMR browse links. No full satellite assets or videos are downloaded by the preview loader. Original download permissions and file hashes are not changed. Reports continue to preserve source metadata; temporary preview bytes are not automatically exported as evidence.

88 automated tests pass, including the previous 63 regression cases plus preview/cache/network/projection tests and an export completion-marker regression. Qt network tests use strictly separated generated fixtures and mocked replies; live Windows checks use real API records and public imagery. Real thumbnails and visible-area map tiles were loaded and inspected in screenshots. A first-show centering defect found visually was fixed and regression-tested. The native source audit searched 88 real records, exercised all seven tabs, export, cancellation and restart successfully.

Audit outputs are private under `private/visual-audit/`; the previous audit remains under `private/audit/`. Public data availability, source capture-date accuracy, all languages/platforms and every machine configuration cannot be guaranteed. Basemaps are current context and previews are source candidates. Authenticated social/video search, local AI analysis, download queues, full-asset permission workflows and true multi-round discovery remain pending.
